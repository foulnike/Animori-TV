# Интерфейс приставки

Правила ниже действуют под классом `.am-lite` на `<html>`, который ставит
`app/platform.ts` по признаку Android. Всё, что касается пульта и плавности,
живёт только здесь: на десктопе этих правил нет.

## Пульт

`app/dpad.ts` водит фокус сам: пространственная навигация движка отключена.
Цель ищется по геометрии, а не по порядку в разметке — `nearest()` сравнивает
отрезки, и смещение в ней означает зазор между ними.

- `preventDefault` на стрелках стоит всегда: без него страница уезжает вместе с
  фокусом.
- Рельс — отдельная полоса: вход в рельс влево, выход из рельса вправо,
  двусторонний ход запрещён.
- `data-am-beside` — спутник крупной соседки: вверх-вниз водят по самим целям,
  кнопка рядом берётся вбок.
- «Назад»: аппаратная кнопка на Android достаётся оболочке раньше страницы,
  поэтому окно обязано сказать наружу, что живо. Этим занимается
  `app/back-stop.ts` вместе с `MainActivity.kt`; вызов включён только пока окно
  открыто, а последний добавленный обратный вызов отвечает первым.

## Кромка фокуса

Кромка рисуется `outline`, а не `box-shadow`: тень срезается `overflow`,
который на полках стоит повсюду. Параметры — в `theme.css`:

```
.am-lite :focus-visible {
  outline: 2px solid rgb(var(--am-accent-rgb) / 0.9);
  outline-offset: -2px;
  box-shadow: inset 0 0 0 999px rgb(var(--am-accent-rgb) / 0.18);
}
```

Два пикселя — потому что кромка должна читаться с трёх метров и не стоить
перерисовки. `inset`-тень с большим распором заливает площадь полупрозрачным
акцентом поверх собственного фона элемента, а не подменяет его.

Где форму рисует не сама кнопка, а потомок, кромку рисует потомок: обойма
портрета, цветок сакуры, поле ввода. Хозяину в этих случаях ставят
`outline: none`. Постеру и плите человека кромка не нужна вовсе — у них свой
отклик формой.

`--am-sh-ring` (1 px) — не кромка фокуса, а тихая обводка самой поверхности;
перепутать их легко, и перепутанная кромка пропадает под `overflow`.

## Плавность

- `content-visibility: auto` на полке ломает прокрутку. Если ускорение всё же
  нужно — `contain: layout paint style`, но не первое.
- Лагает **шаг**, а не среднее: мерить надо крайние значения, а не среднюю.
- Приставка шумная: сравнивать только чередующиеся замеры, иначе разница
  между прогонами больше разницы между вариантами.
- Размытие подложки на приставке стоит сто миллисекунд на кадр не из-за
  видеочипа: подложку под каждым стеклом приходится снимать заново каждый кадр.
  Что именно глушится — список у `.am-lite` в `theme.css`.
- `selectorText = …` на живой таблице стилей бросает
  `NoModificationAllowedError`.

## Рельс

Свёрнутая подпись **место занимает**: пункту ставят `padding: 0; gap: 0`, а
подписи `width: 0; height: 0; overflow: hidden`. Иначе пункт расползается, и
пять вкладок не влезают в экран.

Значок — в `display: grid; place-items: center`. Знак обновления — символом, а
не дугами SVG: три дуги подряд дают заметную погрешность. Величину знака
подбирают по чернилам (canvas и скан альфы), а не по `getBBox()`.

Векторы значков — в `RailIcon.vue`.

## Темы

`app/appearance.ts` ставит `data-am-skin` на корень: фон окна и скроллбары
задаются выше любого экрана. Тем три.

Цвета, радиусы и тени экраны берут только из `theme.css`. Иначе третья тема
оборачивается обходом двухсот мест с `rgba`.

## Мелочи, о которых спотыкаются

- Свои всплывающие подписи (`app/tip.ts`) вместо системного `title`: плашка
  одна на всё окно и живёт в `body` — иначе `scoped`-правила её не достанут, а
  системная подпись не знает ни темы, ни скруглений.
- Окно человека (`app/person-layer.ts`) — общий слой, а не состояние
  компонента: ссылку нажимают и описания, и полки работ, и два окошка спорили
  бы за Escape.
- Плитки: наблюдатель `app/see-tile.ts` один на окно, а не на плитку; просьба
  одноразовая — спросили, сняли с наблюдения. Источники видео спрашивают только
  о том, что человек видел.
- Сакура: геометрия одна на два контекста (`app/sakura.ts`) — подложка кнопки и
  метка рядом с текстом. Числа — в шапке `SakuraBloom.vue`.
- Подписи предметной области — `app/labels.ts`: незнакомый ключ показывается
  как есть, потому что молчаливая пустота хуже латиницы.
- Перехват фокуса должен стоять в фазе захвата: `setTimeout(…, 0)` опаздывает,
  и фокус успевает уехать.
