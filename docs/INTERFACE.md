# Интерфейс приставки

Правила действуют под классом `.am-lite` на `<html>`, который ставит
`app/platform.ts` по признаку Android. На десктопе их нет.

## Пульт

`app/dpad.ts` водит фокус сам: пространственная навигация движка отключена.
Цель ищется по геометрии — `nearest()` сравнивает отрезки, смещение в ней
означает зазор между ними.

- `preventDefault` на стрелках стоит всегда.
- Рельс — отдельная полоса: вход влево, выход вправо, двусторонний ход запрещён.
- `data-am-beside` — спутник крупной соседки: вверх-вниз водят по целям, кнопка
  рядом берётся вбок.
- «Назад»: аппаратная кнопка достаётся оболочке раньше страницы. Окно говорит
  наружу, что живо, — `app/back-stop.ts` и `MainActivity.kt`. Вызов включён пока
  окно открыто; последний добавленный отвечает первым.

## Кромка фокуса

Кромка рисуется `outline`, а не `box-shadow`: тень срезается `overflow`.
Параметры — в `theme.css`:

```
.am-lite :focus-visible {
  outline: 2px solid rgb(var(--am-accent-rgb) / 0.9);
  outline-offset: -2px;
  box-shadow: inset 0 0 0 999px rgb(var(--am-accent-rgb) / 0.18);
}
```

`inset`-тень заливает площадь поверх собственного фона элемента.

Где форму рисует потомок, кромку рисует потомок: обойма портрета, цветок
сакуры, поле ввода. Хозяину ставят `outline: none`. Постеру и плите человека
кромка не нужна — у них свой отклик формой.

`--am-sh-ring` (1 px) — обводка поверхности, не кромка фокуса.

## Плавность

- `content-visibility: auto` на полке ломает прокрутку. Ускорение —
  `contain: layout paint style`.
- Лагает шаг: мерить крайние значения.
- Приставка шумная: сравнивать чередующиеся замеры.
- Размытие подложки стоит сто миллисекунд на кадр. Что глушится — список у
  `.am-lite` в `theme.css`.
- `selectorText = …` на живой таблице стилей бросает `NoModificationAllowedError`.

## Рельс

Свёрнутая подпись место занимает: пункту `padding: 0; gap: 0`, подписи
`width: 0; height: 0; overflow: hidden`.

Значок — в `display: grid; place-items: center`. Знак обновления — символом.
Величину знака подбирают по чернилам (canvas и скан альфы).

Векторы значков — в `RailIcon.vue`.

## Темы

`app/appearance.ts` ставит `data-am-skin` на корень: фон окна и скроллбары
задаются выше любого экрана. Тем три.

Цвета, радиусы и тени экраны берут только из `theme.css`.

## Мелочи, о которых спотыкаются

- Свои всплывающие подписи (`app/tip.ts`) вместо `title`: плашка одна на окно и
  живёт в `body`.
- Окно человека (`app/person-layer.ts`) — общий слой, а не состояние компонента.
- Плитки: наблюдатель `app/see-tile.ts` один на окно; просьба одноразовая —
  спросили, сняли с наблюдения.
- Сакура: геометрия одна на два контекста (`app/sakura.ts`). Числа — в шапке
  `SakuraBloom.vue`.
- Подписи предметной области — `app/labels.ts`: незнакомый ключ показывается
  как есть.
- Перехват фокуса стоит в фазе захвата: `setTimeout(…, 0)` опаздывает.
