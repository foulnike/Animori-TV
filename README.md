**AniMori** — отдельная программа, которая работает с AniList напрямую: сама
запрашивает данные, сама рисует экраны и подтягивает русские названия и
описания с Shikimori и anime365.

AniMori — неофициальный проект и не связан с командой AniList.

> [!NOTE]
> **Где что лежит.** У проекта три продукта, и это отдельный репозиторий
> `foulnike/Animori-TV`. Десктопная сборка — `foulnike/AniMori-AniList-Toolkit`,
> юзерскрипт для браузера — `foulnike/Animori-Script`. Общего кода между ними
> нет.

## Состояние

Версия 3.0 — в разработке. Готового выпуска пока нет. Выпуск делает конвейер по
тегу `tv-<версия>`: два APK, под `armv7` и под `arm64`. Приложение само
проверяет выпуски при запуске; установку подтверждает система, и с Android 8
ей нужно один раз дать право ставить пакеты из неизвестных источников.

## Что уже есть

В меню пять разделов — **Главная**, **Моё**, **История**, **Поиск**,
**Настройки**. Остальные экраны открываются из них: **Тайтл** — из списков и
поиска, **Студия** — чипами карточки, **Просмотр** — кнопкой «Смотреть».

- **Русский по умолчанию** — интерфейс написан по-русски; названия и описания
  подтягиваются с Shikimori или anime365 с указанием источника, а часть имён
  приезжает готовым датасетом и показывается без сети вовсе.
- **Списки без ожидания** — коллекция держится местным снимком: открывается
  сразу, работает без сети и не исчезает при отключении счёта.
- **Список остаётся вашим** — ввоз с AniList слиянием или заменой, выгрузка в
  XML формата MyAnimeList (его примут Шикимори, AniList, Kitsu) и копия в
  облако, сейчас Яндекс Диск. Правки на сервер не уезжают — `docs/STORAGE.md`.
- **Свой плеер** — отдельный экран на прямых ссылках, без чужого кадра и его
  рекламы. Источников два: Aniliberty и Kodik, оба отдают HLS — `docs/VIDEO.md`.
- **Страница тайтла** — описание и названия по-русски, персонажи и персонал с
  русскими именами, студии — отдельным экраном, кадры и трейлер — плиткой,
  музыка — опенинги и эндинги с AnimeThemes полосой внизу окна.
- **Календарь выхода** — на главной, под шапкой: что и когда выйдет у того, что
  вы смотрите.
- **История** — что смотрели, свежее вперёд; продолжить можно в одно нажатие.
- **Поиск по-русски** — по названиям тайтлов, а также по персонажам и
  персоналу.
- **Запросы мимо страницы** — к API обращается процесс программы, а не
  веб-часть: ограничения CORS её не касаются, заголовки под контролем.
- **Вход в AniList** — в браузере устройства; токен ложится в оболочку и наружу
  не уходит.
- **Управление пультом** — фокус ходит по стрелкам сам, рельс — отдельной
  полосой, «Назад» закрывает окно поверх экрана, а не листает историю —
  `docs/INTERFACE.md`.

## Чего здесь нет

| Чего нет | Почему |
| :--- | :--- |
| Манги | в приложении её нет: каталог и списки — только аниме |
| Отправки правок на AniList | сервер их из программы не принимает: список односторонний, вывоз — файлом или копией в облако |
| Обновления без спроса | приложение только находит выпуск новее и отдаёт файл системе; ставит человек, один раз дав право на установку из неизвестных источников |
| Браузера наружу | на приставке его нет, поэтому внешние ссылки не открываются |
| Блокировщика рекламы | свой плеер играет прямые ссылки, чужой кадр не используется |

## Требования

Android TV, Android 7.0 и выше, 32-разрядная платформа (`armeabi-v7a`). Пульт
обязателен: сенсорный ввод интерфейс не использует.

## Сборка из исходников

```bash
npm install
npm run build:app
npm run tauri -- android build -t armv7
```

Подробности, подпись и грабли инструментов — в `docs/BUILD.md`.

## Источники данных

| Источник | Назначение |
| :--- | :--- |
| `graphql.anilist.co` | данные и списки AniList |
| `shikimori.rip`, `shikimori.io` | русские названия, описания, персонажи, франшизы (зеркала одного сервиса, опрашиваются по очереди) |
| `smotret-anime.online`, `anime365.ru` | тайтлы и описания (альтернативный источник anime365) |
| `anilibria.top`, `kodik-api.com` | прямые ссылки на видео для своего плеера |
| `graphql.animethemes.moe` | опенинги и эндинги |
| `cloud-api.yandex.net` | облачная копия списка, только по нажатию и только с вашим пропуском |
| `github.com` | датасет русских названий (`foulnike/animori-data`) |
| `api.github.com` | список выпусков: проверка обновления при запуске, только номер версии |

Запросы идут из процесса программы. Ваши данные на сторонние серверы не
отправляются: токен и настройки остаются на вашей машине, кэш — локальный.
Облачная копия уходит только на ваш собственный диск и только тогда, когда вы
нажали кнопку.
